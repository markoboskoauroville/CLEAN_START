# The icon of Clean Start (Mantra)

Drawn in code by `tools/make_icon.swift`, run by `build.sh` on GitHub (never on the Mac): six white letters
**CLE / STA** (CLEan STArt), SF Pro Rounded Black, over one element, the **power symbol** (what the app governs: what
happens at power-on), white at 46 %, on the black tile of the unpromoted apps (MANTRA_MANIFEST six-letter-icon.md,
DEFAULT LOOK). `six_1024.png` here is the render taken from the release build (Contents/Resources/six_1024.png).
